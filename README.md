# TubeBeacon

TubeBeacon enables distributed, real-time data processing across networked nodes, facilitating auto-scaling and robust platform engine performance.

TubeBeacon is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/TubeBeacon.git`
2. `cd TubeBeacon`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TubeBeacon, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
